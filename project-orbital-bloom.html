Orbital
Bloom.

Overview

System-led visual design for an optimistic science-fiction garden in the sky.

Orbital Bloom is an art direction study for a future where growing things is a collective act. The work focused on defining a modular visual system that could move between intimate plant life and enormous orbital structures.

I created the colour script, shape language, environment keys and reference framework for the project.
